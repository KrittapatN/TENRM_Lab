## 1. Team members / สมาชิกห้องปฏิบัติการ

For **each** member (including alumni) / สำหรับสมาชิก**แต่ละคน** (รวมศิษย์เก่า):

- Full name with title (TH + EN) / ชื่อ-นามสกุลพร้อมคำนำหน้า (ไทย + อังกฤษ)
- Role, e.g. "Lab Director", "PhD Candidate" (TH + EN) / ตำแหน่ง เช่น "ผู้อำนวยการห้องปฏิบัติการ" "นักศึกษาปริญญาเอก"
- Category / ประเภท: Head · PhD · Master · Bachelor · Alumni
- Short bio, 1–2 sentences (TH + EN) / ประวัติย่อ 1–2 ประโยค (ไทย + อังกฤษ)
- Photo / รูปถ่าย: JPG or PNG, portrait orientation, at least 600×800 px
  (we will resize and compress) / แนวตั้ง ขนาดอย่างน้อย 600×800 พิกเซล

## 2. Research projects / โครงการวิจัย

For **each** project / สำหรับโครงการ**แต่ละโครงการ**:

- Project title (TH + EN) / ชื่อโครงการ (ไทย + อังกฤษ)
- One-sentence summary (TH + EN) / สรุปหนึ่งประโยค (ไทย + อังกฤษ)
- A paragraph describing goals, methods, and field sites (TH + EN)
  / ย่อหน้าอธิบายเป้าหมาย วิธีการ และพื้นที่ศึกษา (ไทย + อังกฤษ)
- Status / สถานะ: Ongoing (กำลังดำเนินการ) or Completed (เสร็จสิ้น)
- Optional: 1–2 field photos / รูปภาคสนาม 1–2 รูป (ถ้ามี)

## 3. Publications / ผลงานตีพิมพ์

For **each** publication / สำหรับผลงาน**แต่ละชิ้น**:

- Full title / ชื่อเรื่องฉบับเต็ม
- Author list in citation format / รายชื่อผู้แต่งตามรูปแบบการอ้างอิง
- Year / ปีที่ตีพิมพ์
- Journal or conference name / ชื่อวารสารหรือการประชุมวิชาการ
- DOI or link / DOI หรือลิงก์

A BibTeX export or a copy of the lab's CV section is also fine — we can
convert it. / ส่งเป็นไฟล์ BibTeX หรือส่วนผลงานจาก CV ก็ได้ เราจะแปลงให้เอง

## 4. Contact information / ข้อมูลติดต่อ

- Official lab email address / อีเมลทางการของห้องปฏิบัติการ
- Phone number (if it should be public) / หมายเลขโทรศัพท์ (หากต้องการเผยแพร่)
- Confirm the office address and building shown on the site
  / ยืนยันที่อยู่สำนักงานและอาคารที่แสดงบนเว็บไซต์
- Confirm the map pin location is correct / ยืนยันตำแหน่งหมุดบนแผนที่ว่าถูกต้อง

## 5. Home page / หน้าแรก

- Lab mission statement, 2–3 sentences (TH + EN)
  / พันธกิจของห้องปฏิบัติการ 2–3 ประโยค (ไทย + อังกฤษ)
- A hero/banner photo that represents the lab's work (landscape, at least
  1600 px wide) / รูปแบนเนอร์ที่สื่อถึงงานของห้องปฏิบัติการ (แนวนอน กว้างอย่างน้อย 1600 พิกเซล)
